As stated in the README in the root directory disclaimer, this research was completed in Google Colab. The structures may vary. Please make it work for whatever set up you have/need. I will provide the structure and code that I used inside of my Colab Notebook if you wish to copy it 1:1.

The "ColabKaggleGDriveLoad.py" file is set up specifically for MY Google Drive account directory layout. Because of the size of the dataset, if you try to download the dataset locally and then upload into Kaggle, it will often create errors. To fix this, I downloaded it to my GDrive and then linked my GDrive to Kaggle. Then pulled the dataset from GDrive to Kaggle. This fixed it. Note that you must change the GDrive directory within this file to wherever you placed the dataset or it will not work.
